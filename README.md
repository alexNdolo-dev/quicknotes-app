# QuickNotes App

QuickNotes is a lightweight, responsive web application designed for creating, organizing, and searching personal, work, and study notes directly in the browser.

## Features
- **Categorization:** Classify notes under Personal, Work, or Study with visual border highlights.
- **Data Validation:** Prevents blank entries or notes exceeding 200 characters.
- **Search:** Real-time, case-insensitive note search functionality.
- **Data Persistence:** Notes are automatically saved to `localStorage` and persist across page refreshes.
- **Responsive Layout:** Adaptive Flexbox and card interface designed for desktop and mobile devices.
- **Clear All Option:** Quickly remove all notes with user confirmation.
